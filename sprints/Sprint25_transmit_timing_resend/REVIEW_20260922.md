# Engineering review record — self-healing media design (2026-09-22)

Three independent reviewers read spec v2 (backend `SPEC_resend_heal.md`, device `RESEND_DEVICE.md`),
the rev 3 wire contract, the backend parser/ingest code, the device runtime, and the Sprint23/24/25
measurements. Findings below are condensed; the full outputs are in the session transcript. All
findings were folded into v3 of both specs; open decisions are in the backend spec §0b.

## A — wire contract, backend parser, data integrity
| # | Sev | Finding | Folded into |
|---|---|---|---|
| A1 | BLOCK | No chunk state is persisted; every poll rebuilds from a 6 h window and overwrites the partial, so a late heal replaces it with the resent chunks | M1 index-addressed partials (`media_chunks`, merge by (device,key,n)) |
| A2 | BLOCK | Every lookup is by filename; a START-lost keyed media has none → idempotency-key collisions and duplicate rows on promotion | M1b identity `(device_id, media_key)` for the row's life |
| A3 | BLOCK | `captured_at_utc` is the Sofar message time: `RE_TS_IN_NAME` expects colons, wire stamps use hyphens | M1b: derive from key; fix regex; backfill |
| A4 | SHOULD | Parser state is one slot per node; needs per-key slots + legacy slot; chunk regex; 3-char gid must be rejected | §2 grouping |
| A5 | SHOULD | `<HL>` dedupe by text hash collapses repeats | M4: `w=` wake key in the dedupe key |
| A6 | SHOULD | `missing` has no reliable source for partials; Sofar recompute has no pagination and can report held chunks as missing | M1 union; recompute cut |
| A7 | SHOULD | Promotion double-writes/orphans partial objects and can overwrite a working display key | M3 cleanup rules |
| A8 | SHOULD | Key collision under a bad clock is undefined; a unique index would fail the capture | flag, never merge; plain index |
| A9 | SHOULD | `key=` must be a core START key after `length`, never dropped by the budget | §2 placement |
| A10–12 | NICE | Migration shape (additive, not unique); telemetry double-event acceptable; vector list too short | 0012; §8 vectors |

## B — device runtime and field constraints
| # | Sev | Finding | Folded into |
|---|---|---|---|
| B1 | BLOCK | Stopping the daemon in `main()`'s `finally` runs after the cycle closed the port and started the halt | lifecycle owned by each cycle: stop → close → halt |
| B2 | BLOCK | `video_tx` has none of the hooks; its time gate opens a second UART and would race the daemon reader; the continuous recorder already runs a daemon | port list spelled out; pump-only; scope to stills + video_tx |
| B3 | BLOCK | The 38 s baseline is stills where the daemon already starts before the gate; 22–28 s was a guess | benchmark redefined as uptime segments + Spotter anchor; win = video listens at all |
| B4 | BLOCK | `.sent*` outside every retention mechanism; images have none; video payload lives only in tmpfs | `sent/` prune, atomic write, sidecar-only for images, chunk with the sidecar's size |
| B5 | BLOCK | Key from the system clock, which is not always set | key from Spotter UTC only; legacy form otherwise; monotonic `last_key` |
| B6 | SHOULD | Message-size ceiling already known (1000 B hard, ~430 B fast path; keyed chunk 398 B) | no shrink; confirm with 100 chunks |
| B7 | SHOULD | Heal bounds inconsistent; `v=1` crosses the 5-min boundary; budget not boundary-aware | ≤ 60/wake, +240 s rule, `v=1/2` cut |
| B8 | SHOULD | Acks/`<HL>` inside a video burst manufacture the measured stall loss | acks and HL only after END |
| B9 | SHOULD | "every mode" must not become "every invocation" | D11 predicate kept |
| B10 | SHOULD | `rsd` does not fit `parse_command`/`CommandState` as written; refused commands re-refuse forever | schema note; refused recorded; dedupe by key |
| B11–12 | NICE | `<HL>` cost/path; byte-identity inventory; END `key=` breaks P4 | END unchanged; rev 5 golden set separate |

## C — rollout, operations, failure modes, product
| # | Sev | Finding | Folded into |
|---|---|---|---|
| C1 | BLOCK | Same as A1 from the ops side; `missing_chunks` truncated at 50 cannot serve as the map | M1 |
| C2 | BLOCK | Delivery is binary per (report minute × bus grid): listener exists ~190 s per window; ladder never measures the unaligned case | §6 rewritten; ladder 3 aligned vs unaligned; ops rule; BM-017 escalation |
| C3 | BLOCK | A rev 5 unit on a rev 3 backend loses 100 % of media; rollback recreates that | M0 lossless fallback first and forever; grouping behind a flag whose OFF = M0 |
| C4 | BLOCK | Identity per `source_id` breaks across node-identity moves; 0012 must chain after 0011 | `(device_id, key)`; history walk; sequence + snapshot |
| C5 | SHOULD | Heals appended after the burst land where the losses were measured | heal before START (Q1) or +240 s cap |
| C6 | SHOULD | Partials arrive ~2× faster than one key per command drains; `v=1` never fits | `rsd` list (Q2); cuts |
| C7 | SHOULD | Command ids and `<HL>` dedupe collide with existing idempotency rules | backend-allocated ids; `w=` |
| C8 | SHOULD | Key uniqueness rests on the clock; stale-clock boot silently merges two media | monotonic key; flag never merge |
| C9 | SHOULD | Retention claims false; still `.sent` duplicates the JPEG | prune; sidecar only |
| C10 | SHOULD | bmcam001 is the wrong live-fire target (145-message wall, TODO-SPOT-001, potted) | live fire on bmcam003/004 (Q5) |
| C11–12 | NICE | Daemon-first scope; operator loop under-specified (id, token, counters, snapshot) | scope; `/missing` fields; cron summary line; snapshot before 0012 |

## Net effect on the plan
Stages S0–S7 in the backend spec §9. New up-front items: M0 fallback, index-addressed partials,
`(device, key)` identity, contract rev 5 sign-off, `rsd` list, delivery-reality gate. Cut from MVP:
`v=1`/`v=2`, Sofar recompute, auto-send, age-window command, CV generalisation, bmcam001 live fire.
