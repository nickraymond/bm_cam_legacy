BM Camera Commands

“On next wake” arms the command locally and fires it the moment the target posts a fresh uplink row (unit awake), so the mailbox drain lands while the BM bus is on and the daemon is listening. Unacked commands are re-sent with the same id (idempotent) after the retry window, then flagged. Mailbox is strict FIFO with no expiry — if delivery is dead across retries, use Un-wedge (erases every pending cloud command for the target, then sends a fresh ping probe; watch for its ack). Rate limit: 1 send/min per Spotter.
